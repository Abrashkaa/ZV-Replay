# ZV Replay Viewer

Веб-плеер реплеев для мода ZV Replay (Arma Reforger).

## Установка

1. Установите [Node.js](https://nodejs.org/) если ещё не установлен
2. Распакуйте папку `replay-viewer` куда удобно (например `C:\ReplayViewer`)
3. Откройте папку в терминале (правая кнопка → "Открыть в терминале")
4. Установите зависимости:
   ```
   npm install
   ```

## Запуск

```
npm start
```

Откройте браузер: **http://localhost:3000**

## Карты

Для отображения карт поместите изображения в папку `public/maps/`:

- `public/maps/everon.jpg`  — карта Everon (скачать ниже)
- `public/maps/arland.jpg`  — карта Arland (скачать ниже)

### Где взять изображения карт

Everon и Arland можно взять из:
- Официальной BI Wiki: https://community.bistudio.com/wiki/Arma_Reforger:Terrain
- Или сделать скриншот карты из игры (откройте карту, сделайте скриншот полного вида)

Рекомендуемый размер: 2048×2048 или 4096×4096 пикселей.

**Важно:** изображение должно быть квадратным и покрывать весь террейн от (0,0) до (sizeX, sizeZ).

Если изображения нет — плеер работает и без него (показывает тёмно-зелёный фон с сеткой).

## Расположение файлов реплеев

```
%LOCALAPPDATA%\Arma Reforger\profile\replay\replay_*.json
```

## Управление плеером

| Действие | Способ |
|---|---|
| Play / Pause | Кнопки или пробел |
| Перемотка | Таймлайн внизу |
| Скорость | Слайдер (1× — 60×) |
| Масштаб карты | Колёсико мыши |
| Перемещение карты | Зажать и тянуть |
| Прыжок к убийству | Клик на строку в списке убийств |
